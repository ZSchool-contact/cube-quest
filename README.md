# 🧊 מסע הקוביות

משחק מיפוי ידע לתלמידים, של [z-school](https://z-school.co.il).

**▶ לשחק: https://zschool-contact.github.io/cube-quest/**

הילד יוצא למסע בשמונה עולמות ואוסף קוביות קסם. כל קובייה שומרת שאלה — עונים נכון,
הקובייה נאספת והיא נמתחת לקרש בגשר. מאחורי הקלעים רץ מנוע אבחון אדפטיבי שממפה את
רמת הידע בשלושה מקצועות, ובסיום מפיק **מפת ידע** (וייצוא JSON) להורה ולמנהלת הפדגוגית.

## מה נמדד

| עולמות | מקצוע | שרשראות |
|---|---|---|
| 1–2 | 📚 עברית | קריאה והבנה · לשון ותקינות |
| 3–5 | 🔢 מתמטיקה | מספרים · פעולות · שברים (יסודי) / מספרים · אלגברה · גאומטריה (ז׳+) |
| 6–7 | 🔤 אנגלית | אוצר מילים ואותיות · דקדוק והבנת הנקרא |
| 8 | 🏰 בונוס | עולם אתגר בלי שאלות |

- **מתחילים לפי גיל**: הגיל נבחר במסך הפתיחה, נגזרת ממנו הכיתה (ניתן לתיקון), וכל
  שרשרת מתחילה במדרגה שמתחת — כדי שהשאלה הראשונה תהיה הצלחה ולא מחסום.
- **כישלון רך**: טעות אף פעם לא חוסמת. הקובייה נשארת במקומה ובנגיעה הבאה מחכה שאלה
  קלה יותר; כשנמצא גבול הידע הקובייה ניתנת במתנה.
- **«עוד לא למדתי את זה 🤷»** בכל שאלה — עדיף על ניחוש.
- **אנגלית נלמדת מכיתה ג׳**: לילדי א׳–ב׳ המשחק הוא שישה עולמות.
- **שמירה והמשך**: אפשר לעצור בין עולמות ולחזור מחר — המשחק זוכר איפה הפסקתם
  (נשמר בדפדפן בלבד, לא נשלח לשום מקום).

## הפעלה

קובץ HTML אחד, עצמאי לגמרי — בלי שרת, בלי התקנה, בלי תלויות חיצוניות. פועל במחשב
(מקלדת: ←/→ תזוזה, רווח קפיצה) ובנייד/טאבלט (כפתורי מגע). אפשר גם להוריד את
`index.html` ולפתוח אותו מקומית.

## על הקוד

הקובץ הזה **מיוצר אוטומטית** ואין לערוך אותו ישירות. המקור — מפת תוכנית הלימודים,
מאגר השאלות, המנוע האדפטיבי וסקריפטי הבנייה — נמצא בפרויקט הפנימי של z-school.
שרשרת הבנייה: `build_game.py` (מזריק את השאלות לתבנית) ← `publish.py` (עוטף במסמך
HTML שלם עם `viewport`, לצורך הגשה מהרשת).
