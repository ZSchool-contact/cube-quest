# 🧊 מסע הקוביות

משחק מיפוי ידע לתלמידים, של [z-school](https://z-school.co.il).

**▶ לשחק: https://cube-quest-snowy.vercel.app**

> הקישור הישן (`zschool-contact.github.io/cube-quest`) מגיש גרסה ישנה — פריסות
> GitHub Pages נכשלו שוב ושוב ב-6.8.26 (הבנייה מצליחה, הפריסה נתקעת ב-`deployment_queued`
> עד timeout), ולכן ההגשה עברה ל-Vercel.

הילד יוצא למסע בשמונה עולמות ואוסף קוביות קסם. כל קובייה שומרת שאלה — עונים נכון,
הקובייה נאספת והיא נמתחת לקרש בגשר. מאחורי הקלעים רץ מנוע אבחון אדפטיבי שממפה את
רמת הידע בשלושה מקצועות, ובסיום מפיק **מפת ידע** (וייצוא JSON) להורה ולמנהלת הפדגוגית.

## מה נמדד

| עולמות | מקצוע | שרשראות |
|---|---|---|
| 1–2 | 📚 עברית | קריאה והבנה · לשון ותקינות |
| 3–5 | 🔢 מתמטיקה | מספרים · פעולות · שברים (יסודי) / מספרים · אלגברה · גאומטריה (ז׳+) |
| 6–7 | 🔤 אנגלית | אוצר מילים ואותיות · דקדוק והבנת הנקרא |
| 8 | 🏰 בונוס | עולם אתגר בלי שאלות |

- **מתחילים לפי גיל**: הגיל נבחר במסך הפתיחה, נגזרת ממנו הכיתה (ניתן לתיקון), וכל
  שרשרת מתחילה במדרגה שמתחת — כדי שהשאלה הראשונה תהיה הצלחה ולא מחסום.
- **כישלון רך**: טעות אף פעם לא חוסמת. הקובייה נשארת במקומה ובנגיעה הבאה מחכה שאלה
  קלה יותר; כשנמצא גבול הידע הקובייה ניתנת במתנה.
- **«עוד לא למדתי את זה 🤷»** בכל שאלה — עדיף על ניחוש.
- **אנגלית נלמדת מכיתה ג׳**: לילדי א׳–ב׳ המשחק הוא שישה עולמות.
- **שמירה והמשך**: אפשר לעצור בין עולמות ולחזור מחר — המשחק זוכר איפה הפסקתם.
  **נדרשת התחברות הורה** (הרשמה באימייל + אישור מייל + הסכמה), וההתקדמות והדוח
  נשמרים בענן כדי שאפשר יהיה להמשיך ממכשיר אחר. הילד/ה אינם רואים דוח או ציונים —
  הדוח מיועד להורה ולמנהלת הפדגוגית בלבד.

## הפעלה

בלי התקנה ובלי תלויות חיצוניות. פועל במחשב (מקלדת: ←/→ תזוזה, רווח קפיצה)
ובנייד/טאבלט (כפתורי מגע).

הפרסום מורכב מ**ארבעה קבצים**: `index.html` (המשחק והמנוע) ושלושה קובצי מאגר —
`bank_hebrew.js`, `bank_math.js`, `bank_english.js`. **להורדה מקומית צריך את
ארבעתם באותה תיקייה**; `index.html` לבדו ייפתח אבל יגיש עולמות בלי שאלות. עד
6.8.26 הכול היה מוטבע בקובץ אחד של 881KB.

## על הקוד

הקבצים כאן **מיוצרים אוטומטית** ואין לערוך אותם ישירות. המקור — מפת תוכנית
הלימודים, מאגר השאלות, המנוע האדפטיבי וסקריפטי הבנייה — נמצא בפרויקט הפנימי של
z-school. שרשרת הבנייה: `build_game.py` (בונה את שלושת קובצי המאגר ואת שלד
המשחק) ← `publish.py` (עוטף במסמך HTML שלם עם `viewport` ומעתיק את קובצי המאגר
לצידו).
